# 学习路由证否 —— 一次本可避免的重复死路

## 结果

| | holdout-24 全链路 | 线上 |
|---|---|---|
| v040（v018 手调规则，32.5% → CAM） | 14.73% | **0.14683** |
| **v046（学习路由，77.2% → CAM）** | **13.54%（−1.19）** | **0.16711（+0.02028）** 🔴 |

**本地 −1.19 点，线上 +2.03 点 —— 符号相反、量级差 17 倍。**
每个改判 session：holdout 净赚 6.4 词，线上净亏 7.8 词。
v046 甚至比历史上 100% 用 MOSS 的 v007（0.16593）还差 → **test 上越多 CAM 越糟，单调。**

## 三条根因（按重要性）

### ① 违反查重纪律 —— 这条路 2026-08-06 已经封死

`CLAUDE.md` 写明「产新方向前必做查重」。**没做。** 而 [[arbitration-signal-must-be-acoustic]]
的失败清单里逐条都是本次做的事：

| 该页已记的失败 | 本次重做的 |
|---|---|
| 选择规则族 **480 配置穷举** → 0 胜出 | 特征子集 × 学习器扫描 |
| **LR / GBDT，1024 段训练，12 维特征，按 session 切分验证** → 0 胜出 | LR/GBDT/RF/树，336 样本，28 特征，GroupKFold by session |
| **说话人数**列为「文本派生盲信号」 | `d_nspk = nspk(MOSS) − nspk(CAM)` |

该页的核心判据一句话就否掉了本次方向：
> 任何**文本派生**的信号都无效，因为它们看不见「文字是否与实际说出的话相符」；
> 只有**音频条件**的信号（teacher forcing 声学似然）有效。

`d_nspk` 是纯元数据派生信号 —— **正是被判为盲的那一族**。

### ② 训练数据本身已被拟合过（CV 看不见的泄漏）

CAM 分支的 `SPLIT_THR`/`MARGIN` 当年就是**在 holdout-24 上挑的**，
`logs/2026-08-10.md` 当时已标注：「阈值在 holdout-24 上调，而它是唯一评测集 —— **循环**」。

于是我的训练数据里 **CAM 是被拟合到这 24 段上的版本**，看起来远强于其真实水平；
MOSS 没有这种优待。路由器学到的「CAM 更好」是这个拟合优势的倒影。

**→ 可推广的教训：对学习组件做样本外验证是无意义的，
如果被比较的另一个系统已经在同一批样本上拟合过。**
GroupKFold / 双重留出**查不出这种泄漏** —— 它在我开始之前就烤进输入里了。

### ③ 触发率一致 ≠ 可迁移（我当时用错了判据）

我用「holdout 79.2% vs test 77.2%」当作可迁移的证据。**这只证明 P(x) 分布对齐，
完全不证明 E[Δerror | x] 对齐** —— 而后者才是规则的价值所在。
两处 d_nspk 分布几乎相同，条件收益却符号相反，正是这个区分的活证据。

## 当时就摆在眼前、却没当回事的红旗

1. **规则触发率 79%，oracle 只有 42.6%** —— 我把这行打印出来了，没停下来想。
   一条比 oracle 多触发近一倍的规则，只有靠「错时错得特别惨」的不对称才净正，
   而这种不对称是**最依赖具体样本**的量。
2. **61% 的 test session 落在 d_nspk=0 桶**，而该桶在 holdout 上的边际只有
   5451 vs 5130（**6%**），样本来自 24 段的 219 个相关样本 —— 刀刃上的判断。
3. **自助 95% 区间 [−3.394, +0.559] 含 0**。我写了「未达统计显著」然后照发。

## 补：灾难性失败检测也不可行（2026-08-24）

路由轴此前封死的是「边际择优」。本次问的是不同的问题：
**MOSS 会整段崩掉（test 295 段 MOSS 输出 0 段），能不能认出来并回退 CAM？**

空间是真的：106 段干净集上，**pick 选了 MOSS 但 CAM 更好的有 28 个 session，
合计多错 260 词 = 1.337 点**。最惨的几个 MOSS 错误率 32–38%（正常约 15%），
确属整段崩坏而非边际劣势。

### 但没有可观测信号

| 特征 | 与「MOSS 比 CAM 差」的相关 |
|---|---|
| MOSS/CAM 文本相似度 | **r = +0.055** |
| 词数比 | +0.065 |
| 段数比 | +0.130 |

按文本相似度分四位：最分歧的 Q1 中 MOSS 更差仅 **31%**，
最一致的 Q4 反而 **54%** —— **非单调，方向不成立**。

这坐实了 [[arbitration-signal-must-be-acoustic]] 里那条悬而未决的判断：
**「难」≠「换一个源就更好」**。文本自一致度能预测「这段难」（r=0.441），
却完全不能预测「MOSS 崩了」（r=0.055，小 8 倍）。

三个特征的相关系数均落在 0.05–0.13，正是 `logs/2026-08-08` 立的
**区分度量级门**要求「直接停、不必扫阈值」的区间。

**结论：1.337 点的可回收损失是真的，但灾难性失败不可观测。路由轴第三次封死。**

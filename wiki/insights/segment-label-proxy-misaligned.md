# 段级「标签对不对」是错的代理目标 —— 命中率 73% 仍换不来 tcpWER

## 一句话

**tcpWER 做的是 session 级的全局最优说话人映射**，所以「把某一段的标签改成它自己
重叠最多的 ref 说话人」是**局部正确、全局未必**。把单段改"对"会改变全局映射并连锁，
段级命中率再高也不转化为分数。

## 证据

信号本身很强（见下），但兑现为负：

| 模型 | 基线 | +声学归属改写 | Δ |
|---|---|---|---|
| ho_bs16_wa | 14.50% | 13.79% | −0.706 |
| wa_ho_sim（出货配置）| 14.23% | 13.86% | −0.364 |
| ho_ep1_wa | 14.48% | 14.20% | −0.273 |
| ho_w75_wa | 14.57% | 14.77% | +0.205 |
| ho_soup_wa | 14.32% | 14.75% | +0.433 |
| ho_lora_wa | 14.30% | 15.52% | +1.229 |
| ho_adamw_wa | 14.02% | 15.71% | +1.684 |
| **7 模型合并（168 session 实例）** | | | **+0.315**（3 好 / 4 坏）|

标准误约 ±0.32 → **与 0 不可区分，且方向偏负**。

**若只看出货配置那一行（−0.364），会得出完全相反的结论。**
重尾关卡当场就报了警：剔掉贡献最大的 1 个 session 即翻正（+0.114）。

## 被误导的中间指标（全部很漂亮，全部没用）

裁判 = **基座 MOSS**（从未见过 dev）对说话人标记 `[Sxx]` 的 teacher forcing 似然：

| 指标 | 值 | 参照 |
|---|---|---|
| 区分度 | **+3.220** | 文本轴奏效裁判 +1.195；选源轴失败信号 +0.03~+0.08 |
| 边际命中率 @ τ=0.5 | **73%**（27 对 / 10 错，46 次触发 / 7 模型）| 判据线 50% |
| 命中率随 τ 的形状 | **平台 67~77%（τ∈[0.25,2]）**，非刀刃 | — |
| 决策点 | 2221 | — |

**这是本项目见过的最强的归属轴信号**，量级门、命中率门、平台性、跨模型一致性
**四道关卡全过**，最后仍然没有分数。→ 问题不在信号，在**目标函数**。

## 可复用判据（新增）

1. **段级代理必须先验证与 tcpWER 单调。** 本轴上「重叠最优 ref 说话人」这个天然代理
   **不单调**。今后任何按段打标签的机制，先做一次「代理改善 → tcpWER 改善」的相关性检验。
2. **单配置的兑现数不可信，必须多配置合并。** 同一机制在 7 个模型上从 −0.706 到 +1.684，
   跨度 2.4 点。**任何只在一个配置上测出的 ±0.3 级别收益都是噪声。**
   （这条同时解释了 v041–v045 五连退步落在 0.1484–0.1496 的窄带 —— 见 [[finetune-axis-flat-on-text]]。）

## 顺带封死：段级说话人 embedding

同日实测，ERes2NetV2 段级 embedding 够不到归属轴：
即便给**完美档案 + 只用段内窗**，边际命中率仅 **42%**（<50% 拒绝线，净 −11）。
根因是赛题形态 —— 每 2.2 秒换人、23% 的段短于 1 秒，SV embedding 在该尺度上退化。
→ 现有 `spk_reassign` 只改 26/5513 段**不是配置保守，是它在正确拒绝一个弱信号**。

## 同日顺带证否：「去掉 pick」

`logs/2026-08-14.md` 曾记「pick 只比全用 MOSS 好 0.09 点」，据此有过「去掉 pick」的念头。
用同一套 7 模型合并口径重测：**去掉 pick = +2.052 点，7/7 模型一致更差**
（单模型从 +0.751 到 +2.823）。→ **pick 是真有价值的，08-14 那个 +0.09 不成立。**
结合 v046（把 CAM 占比从 32.5% 提到 77.2% → 线上 +0.02028），
**现行 32.5% 的取值两侧都更差 —— pick 处在一个真实的局部最优上。**

## 结论

归属轴的**「按段改标签」子族封死**（两类信号，一强一弱，都不兑现）。
剩下的 4.19 点若要拿，必须动**切分**（53/267 段跨说话人，占空间的 48%），
而不是在既有切分上重贴标签。

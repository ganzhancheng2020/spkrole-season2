# 仲裁信号必须来自音频：16 次失败 + 1 次成功的分界线

> **一句话**：判断「两个 ASR 候选中哪个对」，任何**文本派生**的信号都无效，
> 因为它们看不见「文字是否与实际说出的话相符」；**音频条件**的信号（teacher forcing
> 声学似然）有效，且方向正确。这条分界线解释了 2026-08-06 全部 17 次实验的成败。
>
> 与 [ensemble-oracle-bound](ensemble-oracle-bound.md) 的分工：那页记**空间有多大**（oracle 上界），
> 本页记**怎么捕捉**（信号有效性）。

## 一、判据来源：16 次失败的共同形状

2026-08-06 一天内做了 17 次「选择/仲裁」实验，前 16 次全部失败。
失败的不是某个参数，是**信号本身**：

| 层次 | 具体信号 | 结果 |
|---|---|---|
| 手工规则 | 选择规则族 **480 配置穷举** | 0 胜出 |
| 手工规则 | TTA 多源 9 种选择器（人数众数/最大值/投票…） | 0 胜出 |
| 手工规则 | 文本 6 种启发式（更长/更短/长度差…） | 0 胜出 |
| 模型内部 | FireRedASR2 **token 级置信度** | 两组差 **0.009**，零区分力 |
| 学习式 | LR / GBDT，**1024 段训练**，12 维特征，按 session 切分验证 | 0 胜出 |
| 语义层 | 独立 LM（Qwen3-0.6B）困惑度，**正反双向 22 组阈值** | 0 胜出，**方向相反** |

**共同点：全部是文本派生的。** 长度、时长、自一致性、说话人数、位置、
模型对自己的置信度、LM 流畅度 —— 没有一个能看见「这段文字是否与实际说出的话相符」，
而这恰恰是仲裁唯一需要判断的事。

### 两个最有信息量的失败

**① 模型自带置信度失败（机制）**：置信度衡量的是 **ASR 对自己输出的确信**，
不是**它相对另一个源的优劣**。一个 ASR 对自己错误的转写同样可以很自信。

**② LM 打分方向是反的（机制）**：

| 分组 | ΔNLL（FireRed − MOSS） |
|---|---|
| FireRed 更好 | −0.159 |
| **MOSS 更好** | **−2.331** |

FireRedASR2 的错误是**流畅的错误** —— 它把听不清的地方平滑成通顺中文，LM 自然给高分。
**流畅 ≠ 准确。** 这是 LM 打分的经典失效模式，也是「文本信号看不见音频」的最锋利证据。

### 一条必须区分的东西

文本自一致度（MOSS 与其 TTA 变体的编辑距离）**确实能预测「这段难」**
（四分位 MOSS 错误 11.66→14.20→20.82→26.10%，严格单调，r=0.441）。
**但「难」≠「换一个源就更好」。** 所有 16 次失败共享这一条：
**能识别困难，识别不了哪个源在该处更优。**

## 二、成功的信号：teacher forcing 声学似然

在 **FireRedASR2-AED 的声学模型**下计算 `P(候选文本 | 音频段)`：

1. 裁出该段音频 → Conformer 编码器 → `enc_outputs`
2. 候选文本 tokenize，前置 `<sos>` 构成 `ys`
3. 走解码器（embed + 位置编码 + `layer_stack` + `layer_norm_out` + `tgt_word_prj`）
4. `log_softmax` 后 gather 目标 token 的 log-prob，**取均值**（长度归一化）

**两个候选在同一声学模型下打分** → 公平比较。

### 自证（下任何结论前先验的两条）

- 文本相同的段，Δ **精确为 0**
- 001 段第 4 条：MOSS「嗯不是有时候像那雾霾的天气要」= −0.2835，
  FireRed「也不是有时候就像那雾霾的天气」= −0.0521，
  ref 为「也不是有时候就像那雾霾的天气要戴」→ **声学分选对了**

### 区分力（与失败信号的对比）

文本不同的 694 段：

| 分组 | 段数 | Δ声学分 |
|---|---|---|
| FireRed 更好 | 226 | **−0.010** |
| MOSS 更好 | 321 | **−1.205** |
| **区分度** | | **+1.195，方向正确** |

对比 LM 打分：区分度 +2.17 但**方向相反**。**方向比幅度重要。**

### ⚠️ 已知偏置及其处理

FireRed 的假设由 beam search 最大化该分数，**天然分高**。
该偏置是**系统性**的，用 train 上校准的 margin 修正即可。
（若两个源都不产出该分数，偏置会消失，但需另找打分器。）

## 三、结果（v024）

| 口径 | MOSS | 声学仲裁（margin=0.05）| Δ |
|---|---|---|---|
| 纯文本 | 12.763% | **11.873%** | **−0.89** |
| 全口径（MOSS 源）| 18.388% | **17.617%** | **−0.77** |
| **集成后（全 dev）** | 16.563%（v020）| **16.090%** | **−0.473** |

- train82 16.806→16.321（−0.485）/ holdout24 15.730→15.297（−0.433），**双切分同向**
- 误差分解 `sub` 1148→1007、`del` 1068→1015，**两项同时降**（非此消彼长）
- **全部 8 个 margin 均通过双切分验收**，非多重比较挑选
- margin 在**真 tcpWER** 上复核仍是 0.05 最优，全区间 16.09–16.14，**平滑无悬崖**
- 捕获率 **43.7%**，与历史 42% 吻合

## 四、可复用的操作规则

1. **判断「哪个源更优」时，先问信号看不看得见音频。** 看不见的一律先验为负。
2. **方向检验优先于阈值扫描**：先分组算信号均值差，方向错就别扫阈值
   （LM 打分若先做这一步，可省下 22 组阈值的试错）。
3. **参与跨分段仲裁的 ASR 必须提供词级时间戳** —— fun-asr 只有段级，重排后
   22.178%（vs MOSS 自己 12.763%），直接出局。这条排除大多数云端 API。
4. **跑 ASR 时务必落盘原始词级时间戳**：不落盘则「词级仲裁 / 跨分段重排」全部需重跑。
   2026-08-06 已因此踩坑一次。

## 五、诚实的边界

- 该方法只解决**文本轴**的仲裁；**归属轴**（说话人）未受益。
- 捕获率 43.7%，剩余 56% 的 oracle 仍未捕捉。方向：n-best 多候选、词级粒度。
- **v024 预期线上约 0.1604，距榜首 0.15023 仍差约 1.0 点** —— 是突破，不是终点。
- ⚠️ 线上预测偏乐观有前科：v020 预测 0.1628、实测 0.16352。**以实际回执为准。**

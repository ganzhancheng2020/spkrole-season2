# 四道关卡：两次校准，一正一反

## 关卡

在 106 段 dev 交叉验证集上（每段由未见过它的模型产生，配方与 v040 一致）跑：

| # | 关卡 | 判据 | 来历 |
|---|---|---|---|
| 1 | **触发广度** | 触发 session ≥ 8 | v047 只触发 2 段 → 线上 +0.00312 |
| 2 | **重尾（整段剔除）** | 剔掉贡献最大的 3 个 **session**（含其全部模型实例）后仍为收益 | v047 时剔的是「(模型,段) 单元格」→ 假通过 |
| 3 | **自助区间** | 对 **session** 重采样，P(更好) ≥ 80% | v011 采信时的同口径 |
| 4 | **符号一致** | 改善 session 数 > 恶化 session 数 | 防「一段吃掉全部收益」 |

## 两次校准

**正向（normalize_output）**：一个真正有效的组件**能过**关卡 ——
四关全过，31 改善 / 0 恶化，自助 P=100%。
→ 关卡不是在无脑否掉一切。

**反向（v049 / `spk_reassign`）**：这次更关键。
干净集上它的点估计是 **+0.062**（看似有害），但**关卡因「触发 3 段 < 8」判不可测**。
交 v049 实测移除它 → 线上 **0.14795（+0.00112）**，即**该组件其实有价值**。

→ **点估计的符号是错的，关卡拦对了。** 若当时信点估计把它去掉，是永久性损失。

## 由此确立的判据

> **触发 session 数 < 8 时，点估计不可用 —— 无论正负。**
> 此时唯一正确的动作是「标记为不可测」，而不是按点估计的方向行动。

这条同时解释了为什么 `spk_reassign` 的「放宽」实验可信：
COH 0.45 与 MARGIN 0.00 两档触发面更宽，且 MARGIN 0.00 档的自助区间
**[+0.015, +1.073] 整体在零以上**（1 改善 / 6 恶化）—— 那是**确定性更差**，不是不可测。

## 尚存的盲点（不要重蹈 v046）

CV 集修的是 **MOSS 侧**污染。**CAM 分支（`cam_re`）的参数当年是在 dev 上调的**，
而 CV 的 106 段全在 dev 内 → **任何涉及 CAM 的比较（尤其路由）在这套集上仍然偏乐观**。
word_arb 的 margin/blocks 只动 MOSS 分支文本，不受此影响。


## 补：改代码做实验时的静默失败（2026-08-21 踩到）

用「字符串替换」给 GPU 上的脚本打补丁时，我的补丁脚本**无条件打印 "patched"，
不校验替换是否真的命中**。结果连续两次假成功：
文件因为已被前一版补丁改过、替换串对不上，实际一行没动，而我以为改好了。

**危害不在于浪费时间，在于会拿着未改动的代码去解读实验结果** ——
那等于把基线的数当成新机制的数，是最难发现的一类错误。

**规则**：任何对代码的程序化修改，每处替换都必须断言命中，
未命中即报错退出；改完立刻 `grep` 关键标识确认出现次数。
本轮修正后四处替换逐条报告 ✅，才继续跑实验。

同源规则：GPU 上的脚本被反复打补丁后状态难追踪 ——
**从本地仓库的干净原版重新上传，再打一次补丁**，比在已改过的文件上叠补丁可靠。

## 固化为一条命令：`src/bench.py`（2026-08-24）

此前每验一个候选都要手工串：pick → normalize → meeteval → 逐 session 拆 →
四道关卡 → 换算线上。**手工口径已出过两次错**（命名空间混用、重尾剔错单位），
故固化成单命令，口径不再漂。

```bash
python src/bench.py --cand <成品目录> --name X       # 对比基线 + 四关 + 预测线上
python src/bench.py --cand <目录> --set-baseline     # 设为新基线
```

基线存 `bench_baselines.json`（含逐 session 分数，便于离线复算）。
输出含**线上落点预测**（迁移率 0.0075/本地点，v048 实测）与「是否够破榜首」判定。

## 顺带审：今天的错误有没有扩散到其他封死结论

有三页完全建立在「24 段 holdout × 多模型」这套已被 [[pooled-models-fake-power]]
否定的口径上、且从未用 106 段干净集复核。逐页审后：

- **`finetune-axis-flat-on-text` 安全**。三条理由：① `erase_speaker` 抹平双侧说话人，
  **无命名空间风险**；② 其主张是「12 变体的**离散度**仅 13 词」，离散度直接可测、
  不依赖池化；③ **有线上外部确认** —— 该页在 v045 回执**之前**预测
  「新旋钮仍落在 9.9–10.2、线上在 v040 附近随机游走」，
  随后 v041–v045 五连退步全部落在 0.1484–0.1496，预测命中。
- **`segment-label-proxy-misaligned` 已于今日复核**（106 段干净集、靶子修正后
  命中率 72%、兑现 −0.026），方向性结论不变。

**结论：今天三个错误的共同点是「拿 oracle 做部分应用」与「靶子定义」，
不是 holdout 口径本身，未扩散到其他结论。**

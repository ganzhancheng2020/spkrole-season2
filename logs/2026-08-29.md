**关键事实**：`word_arb` 改的是 `words` 字段（词级仲裁），**不动 wav 时间戳**。
当 `switched=True` 时，arb 段 wav 与 src 段 wav **完全是同一段时间窗的同一段音频**
（都被送进 `score()` 做 teacher forcing）。

这意味着：
- `emb(src)` = `emb(arb)` （同一段 wav 的两次 forward）= **完全相同**
- `margin_emb = sim(arb, ref) - sim(src, ref)` = **恒等于 0**
- **任何基于"两候选说话人嵌入差"的判官 = 常数信号 = 完全不可用**

**这与声学判官的"capture-rate-scales-with-headroom" 退化是同一层死因**：
当 word_arb 的两候选在同一段 wav 上做文本级仲裁时，**所有音频派生特征
（声学似然 / 说话人嵌入 / 能量）都是退化的**——它们只能反映 wav 本身，
不能反映"换词"决策的正确性。

唯一能区分两候选的，是**文本内容**——而文本派生信号全部已死（精度 32~39%）。

### C. 全面封条（非 ref 信号判官轴）

**封条**：判官轴**结构死**，且死因**逐层显化**：

| 信号族 | 死因 |
|---|---|
| 文本派生（8-28）| 「文本本身是错的」= 错的判官 |
| 声学似然（MOSS / FireRed-AED）| 两候选同段 wav ⇒ 似然差 ≈ 0 ⇒ 信号退化 |
| 说话人嵌入（ERes2NetV2）| 同上 ⇒ 嵌入完全相同 ⇒ 边际信号恒为 0 |
| 结构性 / 物理层 | 精度高但触发面太小；集成也撞不出新盆地 |

**结构性的洞察**：`word_arb` 的机制是「**文本级仲裁，不改 wav**」 ⇒ **所有基于 wav
的判官都在这个机制下退化**（即使是声纹这种"与文本正交"的信号，因为"换词不换说话人"
⇒ "换词不换声纹" ⇒ 信号 = 0）。

唯一可能出货的路径是**改 word_arb 之外的机制**：换 ASR 模型（已知 24h 转写成本不可接受），
或微调 FireRedASR2-AED（已知 3 天内写不出训练循环），或**承认现状**：现有 v067 是最优。

### K. 严格证明：从已知线上分能精确导出的空间里，v065 已是最优

**问题的完整形式**（不是两个特例，是全空间）。设 X 为新产物，`1_X` 为它的「(session, 候选)」
指示向量。则 **X 的分数可精确导出 ⟺ `1_X` 落在 10 个已提交版本指示向量的张成里**，
此时 `S_X = λ·S`。展开条件：设 λ ∈ ℝ¹⁰，则对**每个模式组** g，
把版本按它们在 g 上的选择分块后，**各块的 λ 之和必须全为 0、恰有一块为 1**
（那一块对应的候选即 X 在 g 上的选择）。注意各组都给出 `Σλ = 1`。

**穷举**：10 个已提交版本（v050/v051/v052/v053/v054/v063/v064/v065/v066/v067）、
**30 个模式组 / 394 段**（`v050` 缺 session 295，按「缺失」= 独立候选处理，
对应全删，误差值定义明确，代数仍精确）。
λ 取遍 ≤5 个非零、值 ∈ {−2,−1,1,2}、Σλ=1 的全部组合。

**结果：可行组合恰好 18 个，分数最小的就是 λ = v065 本身（0.14354）**，其余 17 个全部更差
（次优 0.14443 = v063；最好的非单版组合 0.14692 = `v063 − v065 + v066`）。

⇒ **定论：不存在任何「分数可由已知线上分精确导出」且优于 0.14354 的产物。**
**任何改进都必须用额度换新的线上测量** —— 这不是「我没找到」，是穷举后的否定。

（两个已被此结论包含的特例，保留作为可读的推导：① 版本对 —— `S_A − S_B` 精确等于
diff(A,B) 上逐段误差差之和，满足「v065 在 diff 上与 B 全一致」的 10 个对里 B 全部是 v065、
`S_A − S_065` 全为正；② 三版组合 —— `S_A + S_B − S_C` 在 `diff(A,C) ∩ diff(B,C) = ∅`
下恰好等于合法产物的分数，8 个合法三元组全部劣于 0.14354。）

## 十三、5-Why：为什么 oracle 空间 1.4~2.0 点而可达恰好为 0

fork 建链 → 它的推论被我实测证伪 → 用证伪结果收紧成量化因果。**结论比原链更硬。**

### W. 盈亏平衡精度 58.3%，而所有新信号只到 25~35%

dev 忠实对（MOSS=`_cv_mb6` 16.8098%, CAM=`cam_clean2n` 22.2091%），106 段：

| 量 | 值 |
|---|---|
| CAM 真赢 | **30 段（基础率 28.3%）** / 输 68 / 平 8 |
| 路由对了 | +484 errors（2.4888 点），**平均 16.1/段** |
| 路由错了 | −1534 errors（7.8881 点），**平均 22.6/段** |
| **盈亏平衡精度** | **58.3%**（= 22.6 / (16.1+22.6)） |

各信号族在自己最强的档上的实测精度：

| 信号 | 精度 |
|---|---|
| 内容差异（词编辑距离）最大 10/20/30 段 | 10% / 25% / 20% |
| FireRed 第三方词袋一致度最大 10/20/30 段 | 30% / 35% / 30% |
| **出货规则 21 段** | **67%** ← **唯一越过 58.3% 平衡线的** |

### X. 五层因果

1. **可达为 0**：任何扩大路由的规则精度只有 25~35%，**低于 58.3% 平衡线** ⇒ 期望为负。
2. **平衡线为何是 58.3% 而不是 50%**：路由错亏 22.6 vs 路由对赚 16.1，**代价不对称** ——
   因为 CAM 分支整体差 5.4 点（22.21% vs 16.81%），错误路由是把段送进一个真正更差的分支。
3. **为何没有信号能到 58.3%**：基础率仅 **28.3%**，而**七个特征族**（文本派生 / 声学似然 /
   结构性 / wav 物理层 / 声纹嵌入 / 对称编辑距离 / 非对称第三方）与目标的相关都压在 **|r| ≈ 0.22**。
   从 28.3% 抬到 58.3% 需要的提升量远超 r=0.22 能给的。
4. **为何 |r| 卡在 0.22**：这些特征测的是「**两候选差多少**」，不是「**哪个对**」。
   铁证：同一个编辑距离特征，只把 CAM 的文本源从 `relabel(v026)` 换成 fun-asr，
   `r(特征,d)` 就从 **+0.236 翻到 −0.212**，而特征值几乎不变 ⇒ **符号由「哪支平均更好」这个
   外部常数携带，不在特征里**。fork 提出用非对称第三方（FireRed 词袋）破对称，
   **实测 r=+0.223，与对称特征的 0.212 几乎相同 ⇒ 该补救失败，不是对称性的问题**。
5. **结构不变量**：collar 5 下 tcpWER **只是 (说话人→词序列) 的函数**。
   活在这个空间里的 ref-free 信号只有模型自身的置信度，而**候选本身就是该置信度的 argmax**
   ⇒ 判官被要求用生产者自己的信息打败生产者。
   而判官额外拥有的信息（切分 / 时序 / 能量 / 声纹）**恰是度量不变的那些维度** ——
   v078 线上 Δ **精确为 0** 就是这条不变量的直接测量：段数 10→6/10→3，逐说话人词串只差 17/1560 词。

### Y. 为什么出货规则是例外（67%）—— 并且已在最优点

`nspk 不一致` 是唯一同时满足两条的特征：**① 在度量的坐标里**（说话人数直接改变
「说话人→词序列」映射）；**② 方向可解释**（有「MOSS 把两人并成一人」这个先验，
所以 `m_nspk 少 + c_nspk 佐证` 是有向的，不是对称距离）。
所以它能到 67%。而 §V 已证它在四个方向上都无可扩展 ⇒ **已在该轴最优点**。

**⇒ 「可达 0」的完整机制 = 度量不变性（低差异段，Δ 精确 0）+ 精度低于不对称代价的平衡线
（高差异段，符号不可预测）。两个机制各管一半，合起来正好是 0。**
